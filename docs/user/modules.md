# Modules (User Guide)

## Overview

The system is built using modular components, where each module provides specific functionality.

---

## Available Modules

* Foundation → core system features
* User Interface → UI rendering
* User Management → users, roles, permissions
* Organisation → organisation structure
* Integration → external integrations
* Help Support → help center
* Dev → development tools

---

## What Modules Do

Modules help:

* Organize system features
* Enable scalability
* Separate responsibilities

---

## How Modules Work

* Modules are pre-installed
* They automatically provide features and UI screens
* Each module contributes to system functionality

---

## Notes

* Modules work together to form the full system
* Users interact with features provided by modules
